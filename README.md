# 🐦 Bird Species Classifier – 358 Classes  
**Drexel University – Applied Machine Learning Engineering (Summer 2025)**  
**Author:** Akash Adrashannavar  

This project implements a **358-class Bird Species Image Classifier** using **TensorFlow/Keras** and **transfer learning**.  
The model was trained on a large bird dataset mapped using two key label files included in this repository:

- `birdNames.txt` → readable bird species names  
- `birdLabs.txt` → numeric label mappings  

The final trained model is provided here as `model.weights.h5` along with full metadata/configuration files.

This project demonstrates **large-scale multi-class image classification**, which is a highly valued skill in ML engineering and computer vision roles.

---

## 🚀 Project Highlights

- ✔ **358 bird species** (very large multi-class problem)  
- ✔ **Transfer learning** using a pretrained CNN backbone (e.g., EfficientNet / ResNet)  
- ✔ **tf.data pipeline** with augmentation  
- ✔ **Softmax classifier with class mapping**  
- ✔ **Trained weights included (`.h5`)**  
- ✔ **Config + metadata files stored for reproducibility**  
- ✔ **Can be extended to TinyML / Edge AI models**
